## Selected public project

### [Digital Transaction Anomaly Investigation](https://github.com/CalebNaibeiData/Digital-Transaction-Anomaly-Investigation)

A reproducible digital transaction investigation workbench using Python, SQL and synthetic financial records. The project explores suspicious authentication events, transaction patterns and onward fund transfers without treating anomalies as proof of fraud.

Includes an interactive investigation dashboard, a reproducible dataset of 2,440 synthetic payment records, forensic documentation and an analyst decision log.

[Explore the repository](https://github.com/CalebNaibeiData/Digital-Transaction-Anomaly-Investigation) · [Read the investigation report](https://github.com/CalebNaibeiData/Digital-Transaction-Anomaly-Investigation/blob/main/docs/FULL_FORENSIC_REPORT_SIM-2026-002.md)
